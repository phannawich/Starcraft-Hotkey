## View and edit

Use [jcfieldsdev's StarCraft II Hotkey Editor](https://jcfieldsdev.github.io/starcraft2-hotkey-editor/) to view and customize these profiles in your browser.

1. Download a `.SC2Hotkeys` file from this repository.
2. Open the editor and click **Load** to upload the file or paste its contents.
3. Make your changes, then click **Save** and **Download**.
4. Place the saved `.SC2Hotkeys` file in your StarCraft II account's `Hotkeys` folder and select the profile in the game's hotkey settings.

Back up your existing hotkey files before replacing them.
